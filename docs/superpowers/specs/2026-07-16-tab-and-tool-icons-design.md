# Focus Bar Tab 与工具图标设计

## 目标

区分两层图标：每个任务 Tab 拥有独立的主图标；Tab 内的 cmux、VS Code、Chrome 跳转按钮使用对应应用的高辨识度图标。

## Tab 主图标

- 在每个任务配置中增加可选的 `tab_icon` 字段，与任务来源、状态和跳转目标无关。
- 配置窗口在“显示名称”旁增加“Tab 图标”输入框和即时预览。
- 支持一个 emoji 或最多两个字母；保存时按可见字符截取，避免拆断组合 emoji。
- 卡片左上角固定展示 Tab 主图标，任务状态继续由卡片左边框和背景色表达，不再用 `⬜` 等状态 emoji 占据图标位置。
- 未配置时从 Tab 标题生成最多两个字符的缩写；中文标题取首个可见字符，英文按单词或连字符取首字母。

## 工具按钮图标

- 从本机已安装应用的 `.icns` 资源生成并随 Focus Bar 打包三份小尺寸 PNG：cmux、Visual Studio Code、Google Chrome。
- cmux 与 VS Code 的图标按钮只显示应用图标；Chrome 图标继续与链接标签同行显示。
- 保留现有按钮标题、无障碍名称、激活态、点击行为和多链接布局。
- Codex 的 `✦` 图标保持不变，本次不改变其交互。

## 数据与兼容性

- `tab_icon` 保存在对应任务的 `~/.focus.json` 配置中。
- 旧任务缺少该字段时自动使用标题缩写，无需迁移。
- 保存 Tab 图标时继续保留任务的 Chrome、VS Code、状态、备注等其他字段。

## 验证

- 单元测试覆盖 emoji、两个字母、组合 emoji、空值回退和标题缩写。
- Rust 配置合并测试覆盖 `tab_icon` 的新增、清空及其他字段保留。
- DOM 回归测试确认卡片不再渲染状态方块，并使用打包后的 cmux、VS Code、Chrome 图标。
- 安装版验证配置保存、卡片即时更新和三个跳转按钮保持可用。
